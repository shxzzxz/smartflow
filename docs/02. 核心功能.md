# 核心功能

本文档描述 SmartFlow 的功能蓝图，重点说明系统需要向用户提供哪些能力。文档按业务域组织；同一能力跨域时，只在对应业务域描述该域关注的部分。

## 业务域总览

| 业务域 | 域划分状态 | 主要能力 |
| :--- | :--- | ---- |
| 账务核心域 | 确定 | 记账、账户、分类、交易修改、流水、基础统计、月度预算 |
| 信贷域 | 确定 | 借款、还款、账单、分期、合同、还款计划 |
| 数据管理域 | 确定 | 账单导入、导出，数据清理、同步、备份 |
| 理财域           | 待定 |                                                |
| 预设域/规则域 | 待定                         | 周期性账单、模板记账                           |
| 分析域           | 待定             | 自定义统计表盘配置；年度报告               |

## 账务核心域

账务核心域提供个人记账的基础能力，负责记录和展示已经发生的财务事件。

**记账能力：**

- 支持普通支出、普通收入、转账、退款、报销、借出、收回、坏账、借入、还款、债务豁免、期初余额与余额调整。
- 借出、收回和坏账按应收账户总余额记账；借入、还款和债务豁免按应付或借款账户总余额记账，不建立逐笔债权债务或核销关系。
- 收回支持本金与可选利息；坏账和债务豁免不得超过可减少余额，收回和还款超过当前余额时提示确认但不阻断。
- 新建支出（含报销垫付）或收入选择分类后，默认使用该分类最近一笔顶层交易中仍可用的结算账户；没有可用历史账户时保留当前选择。
- 支持已入账交易修改、删除。

**账户与分类：**

- 支持资金、报销、应收、应付、信用和贷款六种账户画像；账务核心使用 `fund / receivable / payable / loan` 子类型判断账户角色。
- 账户类型、子类型和画像创建后不可修改；资产负债账户支持期初余额和余额调整，报销画像是否显示入口由产品层控制。
- 收入、支出分类保持“一级分类 + 二级分类”的活跃两层树，一级和二级分类均可直接记账。
- 支持将单个分类命中的全部交易组原子迁移到同类型活跃分类；迁移与删除是两个独立操作。
- 分类存在子分类或交易引用时禁止删除；无子分类、无引用的分类物理删除，不保留归档归并节点。

**流水与统计：**

- 支持按分类、结算账户和时间范围查询交易；分类与结算账户同时筛选时取交集。
- 一级分类筛选匹配自身及二级分类，二级分类只匹配自身；一级直接金额可通过“未细分”单独钻取。
- 分类统计按活跃两层树汇总，一级总额等于自身直接金额与全部二级分类金额之和；统计区间内存在分录活动的分类即使净额为零也保留。
- 交易列表使用面向列表的分类、结算分录和调整摘要投影；首页只展示顶层交易并汇总退款、报销等调整，账户详情与统计贡献流水展示实际命中的父交易或子交易。
- 详情页可查看当前交易事实与关联子交易。

**预算能力：**

- 支持月度总预算和支出分类预算，并查看已用、剩余和超支状态。
- 支持总预算及分类预算的按日累计支出与剩余趋势。
- 一级与二级分类预算可同时独立设置，金额关系只作提醒，不作为保存约束。
- 分类预算按一级分类分组并支持排序；首页顶部预算信息进入对应月份预算页。
- 支持整笔交易不计入预算；分类迁移只迁移交易，不迁移或合并预算。

**后续扩展：**

- 多账本、家庭账本与多人协作

## 信贷域

信贷域提供借款、还款、分期、合同与账单管理能力，关注用户如何管理负债履约。

**信贷账户：**

- 信贷域提供信用账户、贷款账户的创建与编辑（额度、出账日、还款日、出账日归属）
- 信用账户：消费、取现、垫付计入账期消费净额；账单按出账周期组织
- 贷款账户：无账户级周期参数，账单按月归集合同期次，支持不规则、季供等还款节奏

**借据侧：分期合同和还款计划**

- 贷款分期、现金分期（信用卡贷款）、账单分期产生分期合同与还款计划
- 合同参数与计划解耦：合同详情可跳过或撤销跳过某期，合同编辑页可修改计划行并按参数显式重算
- 合同详情支持状态校验：按实际账单还款分摊修复计划与合同状态，人工跳过保持不变，异常引用只报告不猜测
- 合同创建与编辑共享金融条款校验：手续费、利率不得为负，利率周期与数值必须成对设置；编辑失败不产生部分修改
- 支持合同级提前还款：创建、删除或修改后，以其还款日期为锚点重算锚点之后的待还期次；锚点之前的计划不论状态保持不变
- 重算锚点取事件还款日期与最后一个非 `PENDING` 期次日期中较晚者，重算范围总是一段连续待还尾部，计息起点为锚点期次日期；日期必须按期序严格递增
- 迁移支持：合同可不创建放款交易，已还期次可跳过
- 支持合同维度 IRR、APR、EAR 计算：全部状态（含 `SKIPPED`）的计划本金精确守恒时才计算；实际还款（含提前还款）不改变合同约定现金流指标

**还款侧：账单和还款记录**

- 账单按（账户 × 周期）聚合消费与多合同期次，是统一还款目标
- 账单明细只读，账户详情展示或用户手动刷新时按最新来源重建；修正作用于交易或计划
- 四种还款形态：账单还款、分期还款、提前还款、未归属还款；账单还款和提前还款支持不生成交易（导入、迁移核销），分期还款天然无交易，未归属还款必须有交易；所有还款自持还款时间，并与关联交易时间同步
- 支持部分还、超额还款（提示不阻断）；默认 FIFO 分摊（先费后息后本、先分期后消费），用户可调整明细（本金、利息、手续费、优惠）
- 支持还款交易修改或删除后联动账单状态、还款计划和合同状态
- 还款创建、删除与修改通过 application 核销协调模块推进或回退计划和合同状态；账单生成与刷新只维护账单投影，不改写计划和合同状态
- 支持账单还款、出账后的账内交易退款，退款按入账日期冲减消费净额

**账单查询：**

- 按月账单概要查询；日历页按明细还款日展示，逾期按明细判定

**后续扩展：**

- 主动还款提醒、逾期风险、还款压力和额度使用提醒
- 个别账单还款日调整（节假日顺延）

## 数据管理域

数据管理域提供账单导入导出、数据清理、数据同步备份能力。

**导入能力：**

- 支持一木记账、支付宝、微信和国内主流银行的 CSV / XLSX 账单导入；XLS 文件需先另存为 CSV 或 XLSX。
- 导入流程包含字段映射、预览、调整与提交。
- 支持导入前修正账户、分类、交易类型和备注。
- 支持导入草稿去重和异常提示。

**清理能力：**

- 支持按分类、账户、时间范围组合条件批量清理交易，条件之间取交集。
- 清理以交易组为单位：删除顶层交易及其全部子交易，并同步回冲账户余额。
- 执行前提供命中数量预览与二次确认；清理为物理删除，不可恢复。
- 带业务归属的交易组（如信贷还款、分期放款）不在账务侧清理，自动跳过并提示到所属业务域处理。

**备份与恢复：**

- 备份是包含账务、信贷、导入和用户偏好的完整逻辑快照，采用 `manifest.json` 与分区 NDJSON 文件保存。
- manifest 记录格式版本、应用/schema 版本、创建时间、本位币、必需文件、行数、字节数和 SHA-256；UUID、时间和最小金额单位原样保留。
- 恢复先校验文件、引用、复式记账平衡和账户余额，再生成业务差异摘要；确认后整体替换当前本地账本，不支持合并或增量恢复。
- 完全一致时恢复为 no-op；恢复失败不改变当前数据。日志、原始导入文件、临时草稿和 UI 状态不纳入备份。

## 预设域（规则域）

预设域提供周期性账单、模板记账、智能规则等能力支持

**周期记账能力：**

- 支持固定周期支出、收入，到期后自动生成交易。
- 支持设置周期规则启停状态。
- 自动生成的交易与手动交易遵循同一修改和删除规则。

**智能规则能力：**

- 支持用户配置关键词或正则规则，匹配分类。
- 支持根据历史分类匹配默认账户、备注。

**后续扩展：**

- 订阅管理、周期账单到期确认、自动跳过和复杂日历规则
- 截图记账、语音记账
- 自动记账

## 贷款计算器

贷款计算器是还款计划引擎的无落库演练场，从"我的"页进入。用户填写分期条款，即时生成还款计划，用于核对真实产品的账单口径，并推动信贷域计划规则演化。合同创建、预览与重算复用同一计划引擎。

**条款维度：**

- 还款方式：等额本息、等额本金、先息后本、一次性手续费；一次性手续费在阶段首期还款日一次偿还本阶段应还本金与全部手续费
- 等额本息固定额算法：固定名义期利率、动态实际期利率、指定固定额
- 各期间隔：相邻期次约定间隔的月数；计息方式：按日取实际天数，按月取间隔月数，按年取间隔月数占全年的比例
- 利率单位与标准天数：年 / 月 / 日利率，月按 30 天、年按 360 或 365 天换算
- 舍入方式：四舍五入、银行家舍入、舍去、进一；尾差记入末期
- 分段条款：多个首尾相接的阶段，各阶段可有不同还款方式、利率与期末本金，可表达助学贷款免息期、先息后本转等额本息、气球贷

**输出：**

- 逐期本金、利息、手续费与剩余本金；末期与固定额的差额单列
- 总利息、总还款与合同维度 IRR / APR / EAR
- 提前还款试算：指定已还期次与提前还款日期、金额，按重算锚点规则生成新计划并对照节省的利息

计算器不创建合同、不写入任何数据。

**后续扩展：**

- 分段条款与计算约定落到分期合同
- "月供不变、期数缩短"的重算模式
