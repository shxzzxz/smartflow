# 核心功能

本文档描述 SmartFlow 的功能蓝图，重点说明系统需要向用户提供哪些能力。文档按业务域组织；同一能力跨域时，只在对应业务域描述该域关注的部分。

## 业务域总览

| 业务域 | 域划分状态 | 主要能力 |
| :--- | :--- | ---- |
| 账务核心域 | 确定 | 记账、账户、分类、交易更正、流水、基础统计 |
| 信贷域 | 确定 | 借款、还款、账单、分期、合同、还款计划 |
| 预算域 | 待定 | 总预算、分类预算、预算趋势、超支预警 |
| 数据管理域 | 待定 | 账单导入、导出，数据同步、备份 |
| 理财域           | 待定 |                                                |
| 预设域/规则域 | 待定                         | 周期性账单、模板记账                           |
| 分析域           | 待定             | 自定义统计表盘配置；年度报告               |

## 账务核心域

账务核心域提供个人记账的基础能力，负责记录和展示已经发生的财务事件。

**记账能力：**

- 支持普通支出、普通收入、转账、退款、报销、借入、还款、期初余额与余额调整。
- 支持已入账交易更正、删除。

**账户与分类：**

- 支持资金账户、报销账户、信用账户、贷款账户。
- 支持分类管理。

**流水与统计：**

- 支持基础交易流水查询、筛选
- 支持退款、报销等子记录折叠到父交易详情中
- 详情页可查看更正、冲销与关联子记录链路。

**后续扩展：**

- 多账本、家庭账本与多人协作

## 信贷域

信贷域提供借款、还款、分期、合同与账单管理能力，关注用户如何管理负债履约。

**信贷账户：**

- 信贷域提供信用账户、贷款账户的创建与编辑（额度、出账日、还款日、出账日归属）
- 信用账户：消费、取现、垫付计入账期消费净额；账单按出账周期组织
- 贷款账户：无账户级周期参数，账单按月归集合同期次，支持不规则、季供等还款节奏

**借据侧：分期合同和还款计划**

- 贷款分期、现金分期（信用卡贷款）、账单分期产生分期合同与还款计划
- 合同参数与计划解耦：合同详情可跳过或撤销跳过某期，合同编辑页可修改计划行并按参数显式重算
- 合同创建与编辑共享金融条款校验：手续费、利率不得为负，利率周期与数值必须成对设置；编辑失败不产生部分修改
- 支持合同级提前还款：创建、删除或更正后重算合同内全部 `PENDING` 计划；所有非 `PENDING` 计划保持不变并作为固定本金
- 重算按完整期次时间线确定每个 `PENDING` 的计息起点，前一 `PAID / PARTIALLY_PAID / SKIPPED / PENDING` 日期均参与；日期必须按期序严格递增
- 迁移支持：合同可不创建放款交易，已还期次可跳过
- 支持合同维度 IRR、APR、EAR 计算：全部状态（含 `SKIPPED`）的计划本金精确守恒时才计算；实际还款（含提前还款）不改变合同约定现金流指标

**还款侧：账单和还款记录**

- 账单按（账户 × 周期）聚合消费与多合同期次，是统一还款目标
- 账单明细只读，账户详情展示或用户手动刷新时按最新来源重建；修正作用于交易或计划
- 四种还款形态：账单还款、分期还款、提前还款、未归属还款；均支持不生成交易（导入、迁移核销）
- 支持部分还、超额还款（提示不阻断）；默认 FIFO 分摊（先费后息后本、先分期后消费），用户可调整明细（本金、利息、手续费、优惠）
- 支持还款交易更正或删除后联动账单状态、还款计划和合同状态
- 还款创建、删除与更正通过 application 核销协调模块推进或回退计划和合同状态；账单生成与刷新只维护账单投影，不改写计划和合同状态
- 支持账单还款、出账后的账内交易退款，退款按入账日期冲减消费净额

**账单查询：**

- 按月账单概要查询；日历页按明细还款日展示，逾期按明细判定

**后续扩展：**

- 主动还款提醒、逾期风险、还款压力和额度使用提醒
- 个别账单还款日调整（节假日顺延）

## 预算域

预算域提供支出目标管理和预算执行跟踪能力。

**预算能力：**

- 支持月度总预算和分类预算。
- 支持查看预算已用、剩余和超支状态。
- 支持预算趋势展示。
- 支持整笔交易不计入预算。
- 分类迁移时，支持预算同步迁移

**后续扩展：**

- 年度预算、预算结转、多周期预算和家庭预算

## 数据管理域

数据管理域提供账单导入导出、数据同步备份能力。

**导入能力：**

- 支持一木记账、支付宝、微信和国内主流银行的 CSV / Excel 账单导入。
- 导入流程包含字段映射、预览、调整与提交。
- 支持导入前修正账户、分类、交易类型和备注。
- 支持导入草稿去重和异常提示。

## 预设域（规则域）

预设域提供周期性账单、模板记账、智能规则等能力支持

**周期记账能力：**

- 支持固定周期支出、收入，到期后自动生成交易。
- 支持设置周期规则启停状态。
- 自动生成的交易与手动交易遵循同一更正和删除规则。

**智能规则能力：**

- 支持用户配置关键词或正则规则，匹配分类。
- 支持根据历史分类匹配默认账户、备注。

**后续扩展：**

- 订阅管理、周期账单到期确认、自动跳过和复杂日历规则
- 截图记账、语音记账
- 自动记账

## 个性化设置

**财务周期设置：**

- 账单月起始日默认为 1 号，支持自定义。
- 日历周起始日默认为周日，支持自定义。

**显示设置：**

- 支持分类精简显示。
- 支持流水页是否显示具体时间。
- 支持退款等场景是否显示原金额。
- 支持流水列表是否显示账户图标。
