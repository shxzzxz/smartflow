# 账单为中心的信贷还款模型

信贷域采用**账单（Bill）为中心**的还款模型：账单是用户还款面对的统一目标，按 `(账户, 周期)` 唯一，内部由账单明细汇集消费与多个合同的期次。账单明细是借据侧计划与消费事实的**只读投影**——落库但不可编辑，账户详情展示或用户手动刷新时按来源重建；修正一律作用于来源（交易、计划）。核销以本金为准，由还款明细统一承载；账单分期是一种还款形态，不是明细状态。

账单生成双轨：信用账户**周期驱动**（出账日截单、窗口链式衔接），贷款账户**合同驱动**（期次按月归集进账单，无账户级周期参数）。

## Considered Options

- **还款直接绑计划期次（原模型）**：拒绝。无法承载出账日汇总消费、多合同合并账单、一次还款跨合同；消费信贷（无计划）无处安放。
- **账单只作实时聚合视图、不落表**：拒绝。部分还款归属、出账定格、与真实账单的差异对账都需要稳定的明细载体。
- **为消费信贷建"信用合同"求对称**：拒绝。合同 ⟺ 多期还款计划，消费信贷无计划，强建退化成空壳并复制账户余额。
- **出账后账单冻结不可变（本 ADR 初版）**：拒绝。补记交易、修改入账时间、计划修正都需要修正路径；账户详情只刷新展示账单，用户也可手动刷新任意状态账单。
- **账单明细可手工编辑**：拒绝。改消费明细会与账户余额失配，改分期明细会与合同本金失配；修正一律作用于来源，利息 / 手续费差异由还款表单据实填写吸收。
- **贷款账户沿用账户级出账 / 还款日锚点（本 ADR 初版）**：拒绝。强制期次对齐账户周期无法表达末期对齐整年、季供等真实合同条款；改为合同驱动按月归集，"期次对齐账户周期"约束整体删除。
- **账单分期用明细状态 CONVERTED 表达**：拒绝。无法表达"明细 400 = 现金还 200 + 分期还 200"的混合核销，部分转分期还要拆明细行；分期还款作为还款形态统一走还款明细。
- **预生成未来全部期次账单（Eager）**：拒绝。信用账户只维护上一已出账周期与当前 OPEN 周期；贷款账户只生成当期账单，不生成 `+1` 期。
- **独立核销实体（核销单）**：拒绝。核销是"明细离开待还"的事件，由还款明细承载即可，不需要第四张表。
- **提前还款重算全部 `PENDING`，后置固定本金参与前置期次计息（本 ADR 初版）**：拒绝。发生在第 9 期之后的提前还款会改写第 5–7 期这类更早的待还期次，与产品已确定的历史期次对不上；状态交错时还要把后置固定本金加回前置期次的计息余额，机制复杂却只服务乱序记录。改为重算锚点：锚点之前不论状态一律冻结，锚点之后是连续待还尾部，重算就是对尾部的一次阶段计算。
- **还款记录不存日期或仅无交易时存日期**：拒绝。还款时间属于每笔还款自身的业务事实，不应随是否生成交易改变记录形态。所有还款自持还款时间；有交易时由信贷应用用例在同一数据库事务内同步维护交易时间，避免两个时间各自修改产生差异。

## Consequences

- 还款侧 `bills` / `bill_items` / `repayments` / `repayment_items` 四表；`installment_repayments` 废弃。
- 还款记录**不存金额**：金额 = Σ 还款明细分项。所有还款自持还款时间，作为展示与重算锚点的依据；关联交易时间由信贷用例同步维护，还款账户从当前交易派生。`BILL` / `PREPAYMENT` 的 `transaction_id` 可空（导入 / 迁移核销），`INSTALLMENT` 天然无交易；`UNATTRIBUTED` 必须关联账务还款交易。
- 状态重判同时考虑应还金额、引用存在性和本金：存在应还金额且无还款明细引用为 `PENDING`；完全无应还金额的占位明细为 `PAID`；存在引用但本金未足额为 `PARTIALLY_PAID`；本金足额为 `PAID`。利息 / 手续费不阻塞核销。
- 还款创建、删除与修改通过 application settlement coordinator 推进或回退计划和合同状态；显式跳过或恢复通过合同聚合改变计划状态；合同详情可由用户显式按有效还款分摊校验并修复计划与合同状态；账单生成与刷新只重建账单投影，不把账单明细状态写回计划和合同。
- 提前还款统一为合同级 `PREPAYMENT`；有效提前还款本金创建、删除或修改后，以其还款日期为锚点重算锚点之后的待还期次，锚点之前的计划不论状态保持不变；不含本金的提前还款不改变计划；不跳过计划、不关闭合同。计划修改不自动刷新账单。
- 重算锚点取触发事件的还款日期与最后一个非 `PENDING` 期次日期中较晚者，因此重算范围总是一段连续的待还尾部；尾部计息起点为锚点期次日期，剩余可分配本金在尾部内整体分配并由末期吸收尾差。日期必须按期序严格递增；锚点之后没有待还期次而仍需分配本金时明确失败。
- 合同 IRR / APR / EAR 只消费合同与全部状态（含 `SKIPPED`）的计划现金流；实际还款（含提前还款）不参与资格判断。计划本金之和精确等于合同本金后，再判断现金流充分性和利率解。
- **现金分期放开**：DISBURSEMENT 合同可挂信用账户；合同期次节奏由挂载账户类型决定（信用账户按账期生成、贷款账户按合同条款），产品标签（贷款 / 现金 / 账单分期）读侧派生。
- 额度、欠款分桶、出账预览、IRR 均为读侧派生；来源变化在刷新前体现为未归属欠款差额。
- 信贷账户参数（额度、出账日、还款日、出账日归属开关）由信贷域 `credit_liability_accounts` 持有并提供创建 / 编辑接口。
- `BillItem.id` 只保证同一账单内连续刷新稳定；期次跨账期后创建新物理明细，旧投影在原账单刷新后删除。
