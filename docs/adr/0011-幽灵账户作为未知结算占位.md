# 幽灵账户作为未知结算占位

SmartFlow 保持幽灵账户为 `SystemKey.ghostAccount` 标识的系统权益账户，但允许它在账户角色校验中承担结算账户和还款资金来源，用于表达外部来源明确给出的“无账户”。该例外只按系统身份生效，不改变普通权益账户的角色，也不把幽灵账户改造成资产账户；这样可以完成复式过账，同时避免虚构资产进入资产负债与净资产口径。

## Considered Options

- 把幽灵账户改为资产账户：拒绝，因为它会成为虚构资金余额并进入资产统计与账户展示。
- 所有缺失账户都自动使用幽灵账户：拒绝，因为解析失败、未映射与来源明确无账户是不同事实，静默兜底会掩盖数据问题。
- 绕过账务核心账户角色校验：拒绝，因为这会破坏统一过账入口和账户角色不变量。

## Consequences

- 只有来源明确表达无账户时，导入规则才能选择幽灵账户；解析失败或未完成映射仍需用户处理。
- 账户角色校验仅对幽灵账户放行 `settlement` 与 `repaymentSource`，不允许其承担负债目标、借入到账资金或报销应收等角色。
- 幽灵账户不出现在普通资金账户选择列表，也不进入资产或负债统计；相关测试必须覆盖过账平衡、统计口径与删除后的余额恢复。
