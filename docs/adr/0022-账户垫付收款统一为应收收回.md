# 账户垫付收款统一为应收收回

账户垫付的到账与结清在顶层没有独立于应收收回的账务事实，也没有账户级结清状态或差额处理。账户垫付的分次收款、最后一笔收款和可选利息统一使用 `RECEIVABLE_COLLECTION`，产品只提供“收回”入口；`ADVANCE_COLLECTION` 与 `ADVANCE_SETTLEMENT` 仅保留为逐笔垫付的子交易，分别表达受父交易待收回金额约束的到账和包含差额处理、结清锁的最终结算。

## Consequences

- 普通借出与账户垫付共用单一结算资金账户的应收收回，不新增多账户收款能力。
- 账户垫付最终收款仍是一笔普通应收收回，账户余额归零或相关账户汇总余额归零可作为派生展示，不建立交易级关闭状态。
- 逐笔垫付继续保留到账和结清子交易，避免把差额归类、垫付坏账和结清锁塞入通用应收收回。
- 当前不存在账户级 `ADVANCE_COLLECTION` 或 `ADVANCE_SETTLEMENT` 历史数据，因此不提供此类数据的专项迁移。
