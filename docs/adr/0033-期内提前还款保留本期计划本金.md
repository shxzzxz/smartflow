# 期内提前还款保留本期计划本金

## Status

accepted

## Decision

提前还款落在第 N 期计息范围内时，提前还款本金是额外本金，不替代或重算第 N 期原计划本金。第 N 期利息以还款日次日为本金变化边界，前后分别按原本金和剩余本金计息；第 N+1 期起保持原期数和计划日期重算期供。若第 N 期期初本金扣除本次提前还款本金后小于原计划本金，第 N 期计划本金取剩余本金。该决定解决 [#82](https://github.com/shxzzxz/smartflow/issues/82) 中提前还款被错误回填到计息期初、导致少算利息的问题。

## Considered Options

- **先扣提前还款本金，再从第 N 期期初重算计划**：拒绝。它会让当期计划本金被替换，并把还款前的利息也按剩余本金计算，与真实还款事实不一致。
- **第 N 期完全不变，从第 N+1 期才按原本金重算**：拒绝。还款后到第 N 期结束之间已经使用较低本金，这段时间的利息必须拆分。
- **月供不变、缩短期限**：本轮不采用。该场景会改变期数或末期日期，和“期数不变、仅期供改变”的计算规则分开处理。

## Consequences

提前还款使全部期次的本金、利息和手续费归零后，这些期次判为 `PAID`，合同投影为 `SETTLED`；不通过自动设置 `SKIPPED` 表达结清。仍有利息或手续费应还时，期次继续为 `PENDING`，合同保持 `ACTIVE`。已落库账单不会因计划重算自动改写，仍需按现有规则显式刷新。
