# 提前还款默认结清已产生利息

提前还款时通常同时支付截至还款日的已产生利息。若还款计划继续保留这些利息片段，同一期会同时出现提前还款实际支付的利息和到期再次要求支付的计划利息。计划计算因此需要区分本金变化、利息结清和退款还本，同时避免要求用户额外确认一个通常必然成立的业务事实。

## Decision

- 含本金或利息的提前还款默认结清截至还款日已产生的利息，不提供“是否结清”选项。
- 本金仍从还款日次日起改变计息本金。第 N 期计划本金继续遵守 [ADR-0033](0033-期内提前还款保留本期计划本金.md)；计划待还利息只包含最后结清边界之后的尾段。
- 同一期存在多次提前还款时，以最后一次结清边界为准；同日提前还款合并本金变化和结清边界。还款日恰为当期还款日时，当期剩余利息为零，本金变化从下一期生效。
- 实际还款中填写的利息金额是实际支出事实，不用于反推或调整计划尾段。计划尾段仍由合同本金、日期、利率、重定价和利息调整计算。
- 退款还本只减少退款日之后尚未偿还的计划本金，不结清退款日前已产生的利息，也不反向修改已支付利息和手续费。
- 含本金或利息的提前还款在创建、还款日期修改和删除后完整重算计划；仅手续费或优惠的提前还款不改变计划。
- 合同状态统一由全部计划应还金额和有效还款分摊推导。本金归零但仍有待还利息或手续费时合同保持 `ACTIVE`，全部应还金额归零后才进入 `SETTLED`。

## Considered Options

- **把退款还本也视为利息结清**：拒绝。退款不是用户偿还利息，退款日前已产生利息仍需按计划处理。
- **要求用户逐笔确认是否结清利息**：拒绝。含本金或利息的提前还款默认结清是稳定业务语义，额外选项只会增加常态输入负担。
- **用实际填写的利息金额从当期计划利息中扣减**：拒绝。实际金额记录现金支出，计划尾段必须按合同计息规则独立计算，避免舍入和人工金额差异污染计划。
- **仅按本金扣减日期决定结清边界**：拒绝。还款日当天产生的利息也应视为结清，而本金从次日才变化；两个边界必须分开表达。

## Consequences

本金扣减计算输入需要携带“是否结清截至日期已产生利息”的属性。提前还款构造为结清，退款还本构造为不结清，计划引擎据此标记已结清片段并只汇总未结清尾段。合同状态修复继续以全部计划金额为准，不按本金是否归零单独判定。
