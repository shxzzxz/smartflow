# 分析域持有资产视图配置与范围

资产页需要用户保存多个账户观察范围，并在每个视图中分别组织分组和顺序。这些配置具有独立身份、生命周期和跨页面一致性规则，因此由 `analytics` 分析域持有；资产页仍按用户工作流组织在 account feature 中。

资产视图保存明确的账户身份范围、分组定义、账户归组和排序。各视图独立维护组织规则，包括系统提供的默认视图；账户资料与账务统计事实由账务核心提供。按画像分组只用于视图初始配置和新加入账户的默认选择，后续手动组织不改变账户性质。

全局账户分组无法表达同一账户在不同观察范围中的不同安排，也会让账务核心承担观察视角的配置生命周期。将组织规则放入视图会复制部分分组定义，但能使范围、归组、排序、复制和备份保持同一作用边界，免去全局组织与局部覆盖之间的同步规则。

application 负责保存、查询与跨域编排，infrastructure 实现持久化和消费账务能力的适配。账户创建通过所属账务或信贷能力完成，加入当前视图与归组在同一外层事务中完成，任一写入失败时整体回滚。其他视图通过明确编辑范围纳入新账户。

当前视图选择与类型筛选作为浏览状态处理。类型筛选只影响账户展示，统计始终覆盖视图完整范围。账户分组以列表卡片展示，视图配置以一个整体持久化并纳入逻辑备份。

关联需求：[Issue #75：资产页多视图](https://github.com/shxzzxz/smartflow/issues/75)。
