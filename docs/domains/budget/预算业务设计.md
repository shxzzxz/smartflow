# 预算业务设计

预算域负责表达用户按月份和支出分类设置的预算目标，以及预算统计如何消费账务核心的支出分录。

## 1. 业务定位

- 预算绑定支出分类账户；总预算使用空分类账户表达。
- 预算统计只读取账务核心已经确认的支出分录，不改变交易、分录或账户余额。
- 预算排除是整笔交易粒度：一笔交易只要被标记为不计入预算，其所有支出分类分录均不计入预算。

## 2. 数据模型

```text
budgets
- id
- month_key             形如 202605，避免日期时区问题
- account_id            支出分类账户 id；NULL 表示当月总预算
- amount_minor
```

约束：

- `account_id` 非空时只能指向支出分类账户。
- `(month_key, account_id)` 唯一；`account_id` 为 NULL 时按 `month_key` 唯一。
- 预算分类管理与账务核心的交易分类迁移相互独立；分类迁移不触发预算迁移、合并或校验。
- 账务核心删除分类时不查询预算引用。预算功能如何呈现或处理已删除分类属于预算域自身的兼容与交互规则；如需删除前提示或引导处理，由预算 feature / ViewModel 编排。

## 3. 预算统计口径

预算已用金额来自命中预算分类树的支出分录，并遵循账务核心的更正、删除与统计有效性规则。

- 支出分类借方分录增加预算已用金额。
- 支出分类贷方分录抵减预算已用金额，例如退款抵减支出。
- 已更正、已删除或补偿性质的交易不作为当前预算事实。
- 被用户标记为不计入预算的交易整体排除。
