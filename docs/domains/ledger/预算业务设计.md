# 预算业务设计

预算是账务核心中的轻量支出目标能力：只保存某月总预算或某月某支出分类预算，并基于支出分录提供执行提醒，不建立独立预算域。

## 1. 业务定位

- 预算绑定支出分类账户；总预算使用空分类账户表达。
- 预算统计只读取账务核心已经确认的支出分录，不改变交易、分录或账户余额。
- 预算排除是整笔交易粒度：一笔交易只要被标记为不计入预算，其所有支出分类分录均不计入预算。
- 总预算、一级分类预算和二级分类预算彼此独立，均为提醒目标，不构成金额分摊或强约束。

## 2. 数据模型

```text
budgets
- id
- month_key             形如 202605，避免日期时区问题
- account_id            支出分类账户 id；NULL 表示当月总预算
- amount_minor
- sort_order            当月分类预算展示顺序
```

约束：

- `account_id` 非空时只能用于支出分类账户。
- `(month_key, account_id)` 唯一；`account_id` 为 NULL 时按 `month_key` 唯一。
- 不限制一级分类预算大于或等于子分类预算之和，也不因总预算与分类预算的关系拒绝保存。
- 分类迁移只改写交易当前分类，不迁移、合并、删除或校验预算。
- 分类删除不通过数据库外键级联预算；查询只呈现仍有活跃分类的分类预算。

## 3. 预算统计口径

预算已用金额来自命中预算分类树的支出分录，并遵循账务核心的当前事实与预算排除规则。

- 总预算统计当月全部支出分类分录。
- 一级分类预算统计一级分类自身与全部二级分类的支出分录。
- 二级分类预算只统计该二级分类自身的支出分录。
- 一级与二级分类同时设置预算时分别展示各自使用量，不从一级预算中扣除二级预算。
- 支出分类借方分录增加预算已用金额；贷方分录抵减预算已用金额，例如退款抵减支出。
- 被用户标记为不计入预算的交易整体排除；是否计入收支统计不影响预算口径。

## 4. 交互

- 首页顶部收支卡片的“本月预算”区域进入对应月份预算页。
- 预算页展示总预算、已用、剩余或超支、预算趋势及分类预算分组。
- 分类预算按一级分类分组，一级与其二级分类预算相邻展示；分组顺序持久化到预算表。
- 分类预算详情展示该分类预算的使用情况和预算趋势。
