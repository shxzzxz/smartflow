# 录入域设计

## 职责与边界

录入域将用户描述、外部来源资料和已授权周期规则整理为记账输入，负责输入解释、确认或规则执行以及录入结果管理。账户、交易、分项、复式分录、余额和过账规则由账务核心管理。

输入渠道不决定账务行为。截图、语音和文件提供来源信息；录入能力解释业务意图并补全输入，确定后通过账务核心完成记账。各能力使用自己的候选、计划或规则模型，不要求所有输入都具有导入来源、来源映射或导入批次。

## 来源导入

来源导入解释外部来源记录，维护账户与分类映射，组织导入交易组，提交导入批次并编排撤销。解析、映射和审阅状态仅属于当前录入会话；成功提交后保留来源映射、批次及批次详情。

来源导入的规则与模型见[导入业务设计](导入业务设计.md)。其它录入能力的功能规划见[核心功能](../../02.%20核心功能.md)。

## 与账务核心的协作

录入能力拥有来源解释和录入流程，账务核心拥有账务事实与过账校验。录入能力在确认或授权执行后调用账务核心创建交易，撤销导入时调用账务核心删除对应交易组。

录入结果和账务写入处于同一用例事务中：任一账务创建、来源映射或批次写入失败时整体回滚。录入域不复制账户角色、分录平衡和余额计算规则。
