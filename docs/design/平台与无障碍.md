# 平台与无障碍

本文档定义 SmartFlow 的平台范围、Material 基座、触控目标、主题和信息可访问性规则。总体入口见 [05. 设计系统](../05.%20设计系统.md)。

- 当前阶段仅面向 Android。Android 约束应用的系统交互、返回行为、窗口与安全区、键盘、焦点、触控目标和无障碍能力，不限制 SmartFlow 的品牌视觉表达。
- Material 3 作为行为与实现基座，通过 `ThemeData`、设计 token 和基础组件建立 SmartFlow 自有视觉语言，不直接沿用默认 Material 外观作为产品风格。
- 圆角卡片、柔和阴影、品牌色和平台中性的排版可以跨平台使用；不引入 iOS 状态栏、Cupertino 控件、iOS 日期选择器等平台专属交互隐喻。
- 可点击控件不设全局统一的触控尺寸；按使用场景确定触控目标：列表行、按钮、表单控件等主交互保持舒适尺寸，图表浮层按钮、紧凑工具等空间受限场景允许更小的可视尺寸，同时通过扩大透明命中区域保留可点击性，并保留 Flutter Material 控件提供的焦点、状态和语义能力。
- 支持跟随系统暗黑模式，亮色和暗色主题共用同一套 token 源。
- 框架内置菜单与控件文案跟随系统语言偏好，并保留地区和简繁体差异；采用 Flutter SDK 内置资源支持的语言，未匹配时回退简体中文。业务页面目前采用简体中文文案。
- “我的 → 设置”按操作、交易和外观分组；“外观设置 → 主题外观”编辑主题配色和背景。主题色与背景基色默认均为蓝色，独立配置。主题色保留用户选定原值，填充上的文字和图标由 `onPrimary` 选择深浅前景色；收入、支出颜色在交易设置中独立编辑，继续按各自的财务语义映射。背景支持纯色、单色光晕和多色光晕，多色辅助光晕由背景基色派生，亮暗主题分别限制光晕透明度。
- 底部导航的经典与悬浮毛玻璃样式共用覆盖式布局：一级页面内容延伸到导航栏下方，由 App Shell 统一下发滚动内容与悬浮按钮的避让尺寸。经典样式保持全宽、不透明、贴底；毛玻璃样式使用低透明度表面、实时背景模糊与轻微饱和度提升，形成清爽通透的浮层，并保留大圆角与柔和阴影。两种样式保留一致的标签开关、选中状态和触控语义。
- “外观设置 → 导航栏外观”和“外观设置 → 顶部外观”分别管理导航栏及页头，提供局部实时预览、恢复默认与保存。经典顶部使用纯色背景并移除内部控件的悬浮玻璃效果，保持状态栏覆盖、尺寸和交互一致；参数滑杆提供当前值语义，窄屏与大字号下可通过整页滚动访问全部参数。
- 财务正负表达不能只依赖颜色，应结合 `+` / `-`、文案或结构。
- 状态表达不能只依赖颜色，应辅以图标、文案或布局差异。
