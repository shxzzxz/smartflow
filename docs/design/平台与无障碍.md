# 平台与无障碍

本文档定义 SmartFlow 的平台范围、Material 基座、触控目标、主题和信息可访问性规则。总体入口见 [05. 设计系统](../05.%20设计系统.md)。

- 当前阶段仅面向 Android。Android 约束应用的系统交互、返回行为、窗口与安全区、键盘、焦点、触控目标和无障碍能力，不限制 SmartFlow 的品牌视觉表达。
- Material 3 作为行为与实现基座，通过 `ThemeData`、设计 token 和基础组件建立 SmartFlow 自有视觉语言，不直接沿用默认 Material 外观作为产品风格。
- 圆角卡片、柔和阴影、品牌色和平台中性的排版可以跨平台使用；不引入 iOS 状态栏、Cupertino 控件、iOS 日期选择器等平台专属交互隐喻。
- 可点击控件不设全局统一的触控尺寸；按使用场景确定触控目标：列表行、按钮、表单控件等主交互保持舒适尺寸，图表浮层按钮、紧凑工具等空间受限场景允许更小的可视尺寸，同时通过扩大透明命中区域保留可点击性，并保留 Flutter Material 控件提供的焦点、状态和语义能力。
- 支持跟随系统暗黑模式，亮色和暗色主题共用同一套 token 源。
- 财务正负表达不能只依赖颜色，应结合 `+` / `-`、文案或结构。
- 状态表达不能只依赖颜色，应辅以图标、文案或布局差异。
