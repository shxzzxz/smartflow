# 设计系统分层与目录

本文档定义设计系统各层的职责、消费边界和代码目录。总体入口见 [05. 设计系统](../05.%20设计系统.md)。

## 分层结构

```text
Token 源层 -> 主题映射层 -> 基础组件层 -> 业务组件层
```

## Token 源层

Token 源层是项目内视觉原始值的唯一来源，负责颜色、间距、圆角、字号、阴影、动效和图表色等基础值。

约束：

- token 命名按尺度或用途归类，如 `space4`、`radiusMd`、`durationFast`。
- 原始颜色只允许出现在 token 源层，业务页面禁止新增 `Color(0xFF...)`、hex、rgb 等写法。
- token 只定义值，不包含业务判断。

## 主题映射层

主题映射层将 token 映射为 Flutter 可消费的语义入口：

- Material 3 `ColorScheme`：品牌色、背景色、表面色、错误色等通用语义。
- `TextTheme`：标题、正文、标签等文本语义。
- `ThemeExtension`：Material 3 没有覆盖的状态、财务和图表语义。

Material 3 在 SmartFlow 中承担控件行为、状态、无障碍和 Flutter 实现基座，不作为默认视觉模板。按钮、输入框、搜索、页签、选择控件、反馈、弹层和导航等通用外观应在 `ThemeData` 的组件主题中统一映射为 SmartFlow 品牌视觉；只有组件主题无法稳定表达的交互或结构才新增基础组件。

消费边界：

- 颜色、文本、财务语义色优先通过 `Theme.of(context)`、`ColorScheme`、`ThemeExtension` 使用。
- 间距、圆角、动效时长等基础布局值允许通过 `AppSpacing`、`AppRadius`、`AppMotion` 直接使用。
- 页面层不直接读取原始色板 token。

## 代码目录

```text
lib/design_system/
├── token/
│   ├── colors.dart        # 原始色板，不被页面直接消费
│   ├── component.dart     # 通用控件几何、状态透明度和边框 token
│   ├── spacing.dart       # 间距 token
│   ├── radius.dart        # 圆角 token
│   ├── typography.dart    # 字体 token
│   ├── elevation.dart     # 阴影 token
│   ├── form.dart          # 表单几何和状态 token
│   ├── motion.dart        # 动效 token
│   └── chart.dart         # 图表色 token
├── theme/
│   ├── app_color_scheme.dart       # Material 3 ColorScheme
│   ├── app_theme_extension.dart    # 财务、状态、图表等扩展语义
│   ├── app_text_theme.dart         # TextTheme
│   └── app_theme.dart              # ThemeData 组装
├── widget/              # 通用基础组件
└── showcase/            # 组件示例页

lib/widget/business/     # 跨 feature 复用的业务组件，可按视觉语义分组，例如 finance/、transaction/

assets/styles/            # 账户、分类图标资源与 JSON 注册数据
├── preview.html          # 唯一开发预览入口，直接读取 JSON/SVG
├── account/              # 账户风格列表与各套图标
└── category/             # 分类风格列表与各套图标
```

账户、分类分别选择风格；未覆盖的 key 使用通用回退。导航和操作控件继续使用图标库。

交易列表与详情头部共用交易图标组件。转账、借出、借入、还款、收回等图标表达交易用途，由交易业务组件使用图标库统一映射，不进入账户或分类图标目录，也不参与两类图标风格选择。收支及垫付继续使用分类图标；账户流向中的两端继续使用账户图标。转账、借出、借入、还款与收回均按业务角色展示“来源账户 -> 目标账户”，不以收支金额正负推断方向。

导入来源图标由导入模块独立维护，不复用账户或分类图标风格资源。

收支及垫付交易包含多个分类时，列表与详情头部使用固定的多分类网格图标；列表标题为“多类别”，详情标题为“多分类”。单分类仍使用该分类的图标。多分类标识与分类图标缺失时的通用回退分别处理，不从多个分类中任取一个图标。
