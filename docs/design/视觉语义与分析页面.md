# 视觉语义与分析页面

本文档定义 Material、状态、财务和图表语义，以及分析页面的视觉与交互模式。总体入口见 [05. 设计系统](../05.%20设计系统.md)。

## Material 语义

品牌、背景、表面、边框、禁用、错误等通用视觉语义优先使用 Material 3 `ColorScheme` 和 `TextTheme`，不在页面层另起命名。

## 状态语义

通过 `ThemeExtension` 提供：

- `success`
- `warning`
- `danger`
- `info`

`danger` 用于删除、失败、错误等通用危险状态，不等同于支出。

## 财务语义

通过 `ThemeExtension` 提供：

- `income`
- `expense`
- `transfer`
- `asset`
- `liability`
- `equity`

约束：

- `income` 不等同于 `success`。
- `expense` 不等同于 `danger`。
- `transfer` 保持中性表达，不在不同页面随意换色。
- `asset`、`liability`、`equity` 是账户域语义，不退化为具体色名。

## 图表语义

- 通用分析图使用 `chart1` ~ `chart8`：系列槽位按固定顺序取用，不循环复用；系列数超过槽位时尾部折叠为“其他”（`chartOther`）。
- 系列色亮/暗两套均需通过色盲可分性、亮度带与对表面对比度校验后才能进 token；调整色值或顺序后必须重新校验。
- 明确表达财务概念的图表使用财务语义色 `income`、`expense`、`asset`、`liability`、`equity`。
- 同一图表模块内不要混用系列语义和领域语义。

## 分析页面模式

- 页面层不直接配置第三方图表库；坐标轴、刻度采样、tooltip、空状态和图表几何由 `feature/<feature>/widget/` 下的适配组件收口。
- 数值图表必须提供纵轴刻度（金额用紧凑格式，刻度取整到干净数值），tooltip 只做补充信息，不承担唯一读数途径；同一页面的 tooltip 使用统一的反色底样式与金额格式。
- 时间序列必须根据观察区间选择粒度：月度可按日、年度按月，长自定义区间按周或月聚合，避免依赖横向滚动承载过密数据。
- 窄屏横轴只保留少量代表性刻度，并保证首尾刻度不会与相邻刻度重叠。
- 分析页使用“页面身份 → 本期概览 → 主趋势 → 次级分析”的层级，不让所有筛选器和图表拥有相同视觉权重。
- 同一区域存在多个次级展示维度时，保留一个主切换控件，其余选项收进菜单或筛选面板。
- 加载新区间时保留上一次内容降透明度过渡，不整页回退为加载指示。
- 关键分析页面至少保留一个手机宽度下的 widget test，覆盖页面层级、文本溢出和关键交互；系统字体相关视觉在目标 Android 设备上验证。

## 统计视图

- 分析页由页面壳和多个页面级视图组成。“期间分析”和“当前状态”是并列视图，页面壳只负责视图切换与内容承载，不替视图声明统一页头。
- 视图切换使用控件级字号的轻量页面导航，并提供完整的触控高度；它不占用 `AppPageHeader` 的标题位，也不使用页面标题字号。
- 页面 header 不是视图的强制前提。每个视图自行组织顶部上下文与滚动内容：期间分析拥有日期范围和比较上下文，当前状态直接进入资产、负债、分期构成与还款走势。
- 新增统计视图时，页面壳只增加视图类型到视图组件的分支；视图内部独立组织自己的上下文、加载态和内容区块。
- 当前状态以截至某日的余额、结构和义务为口径；期间分析以 `[from, until)` 内的流量、占比和变化为口径。
- 资产与负债构成使用余额快照的带符号总额；负余额账户在列表中保留实际符号，环形图不把其绝对值计入正向构成。
- 当前状态不使用历史区间选择器。分期构成与分期还款走势只统计进行中的分期合同；金额依据当前还款计划估算，实际还款仍以账单和还款记录为准。
- 分期构成通过分段控件切换“待还本金”和“总待还”口径，以合同为切片展示饼图；列表按所选口径从大到小排列，并复用构成列表的左中右三段式结构：左侧色标、中间合同名称与进度条、右侧当前口径金额。进度条下方同排显示待还本金、待还利息与 XIRR 数值，不添加文字标签、下一还款日或分割线。
- 分期还款走势在卡片内先展示待还本金、待还利息与逾期待还，再以本金、利息双柱展示半年、一年或全部剩余期限的月度走势；逾期计入概览但不计入未来走势，不再单独展示逾期提示或月份明细列表。走势图与其他分析图一致提供横屏放大入口。
- 期间分析保留一个页面级日期范围和一个页面级比较基准，不允许多张卡片各自选择不同日期范围。比较基准必须显示具体对比期，不能只写“对比”。
- 期间范围、对比设置入口和对比范围放在同一个上下文组件中。本期是唯一的上下文强调块；环比/同比入口保持低强调，不渲染成选中按钮或选中色块。
- 比较基准使用“环比”和“同比”表达模式，并同时展示实际日期范围，不重复展示“已过天数”等推导说明。
- 当前月、当前年等未完成周期按相同经过天数选择默认对比期；完整月或完整年使用对应历史周期；自定义区间默认使用前一等长区间；无比较数据时保持“无对比”，不得用零值冒充对比期。
- 对比期与本期使用相同的统计口径、筛选条件和聚合粒度。进行中周期优先使用累计趋势，本期与对比期共用纵轴；对比趋势卡不重复放置说明性副标题。分类构成不叠加两个环图，分类行的变化额只解释差异，不改变当前结构的环形图口径。
- 分类、标签等构成列表的对比变化额与条目名称位于同一行右侧，使用“较上期增加/减少”“新增”“持平”等自然语言；金额与占比保持独立列，避免把变化额堆叠到金额列。
- 统计结果按总览、对比趋势、收支趋势、分类、标签和资产走势分别建模和构建；页面只负责组合区块，不消费一个包含全部统计字段的扁平结果对象。
