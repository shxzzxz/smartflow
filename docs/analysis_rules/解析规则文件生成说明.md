基于 `demo/data` 文件夹中的真实导出数据，生成解析规则文件，用于人工核对解析规则。
文件解析中的示例需要脱敏，使用虚拟账户、虚拟金额表达差异类型。

生成的规则文件必须直接链接其依据的 `demo/data` 脱敏样例文件，并列出规则与样例场景的对应关系，便于人工核对规则是否真正来自样例。

脱敏样例必须保留原始导出文件的前导说明区、分隔线、表头位置、列顺序和空列结构，只替换敏感字段值。需要缩减记录时，按来源业务场景抽取代表行，不得重写文件骨架或自行设计场景。

规则文件内容结构如下：

- 文件模版：如何理解各类型文件。按不同类型文件组织，包含文件内容说明，核心字段，特殊字段含义说明
- 名称映射：如何提取账户、分类。阐释账户、分类提取规则
- 文件解析：如何解析各类型文件。按不同文件、不同业务类型组织，说明本类型示例数据以及解析结果。

示例规则文件：`一木记账解析规则.md`
