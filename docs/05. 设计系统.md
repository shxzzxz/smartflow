# 设计系统

本文档是 SmartFlow Flutter 工程设计系统的治理入口，定义视觉值、主题、组件和业务视觉语义在代码中的归属。详细规则按职责拆分到 `docs/design/`。

## 当前阶段

SmartFlow 当前处于 MVP 阶段，以 **A 级：最小可落地版** 为基础，并开始补充 B 级协作能力：

- 建立 token、theme、基础组件和业务组件的分层入口。
- 新增代码必须使用设计系统已有能力，不再扩散原始色值和魔法数。
- 存量代码不做一次性重构，采用“触达即治理”。
- 提供仅调试模式可见的组件示例页，集中检查组件状态、财务语义和手机布局表现。

后续升级到完整的 **B 级：标准协作版** 时，继续补充静态检查规则和更稳定的页面模式库。

## 总体分层

```text
Token 源层 -> 主题映射层 -> 基础组件层 -> 业务组件层
```

设计系统代码与资源的入口如下：

```text
lib/design_system/
├── token/                         # 视觉原始值
│   ├── colors.dart
│   ├── component.dart
│   ├── spacing.dart
│   ├── radius.dart
│   ├── typography.dart
│   ├── elevation.dart
│   ├── form.dart
│   ├── motion.dart
│   └── chart.dart
├── theme/                         # Flutter 主题映射
│   ├── app_color_scheme.dart
│   ├── app_theme_extension.dart
│   ├── app_text_theme.dart
│   └── app_theme.dart
├── widget/                        # 通用基础组件
└── showcase/                      # 组件示例页

lib/widget/business/               # 跨 feature 复用的业务组件
assets/icons/                      # 业务图标资源
```

分层职责、消费边界和目录规则见 [分层与目录](design/分层与目录.md)。
