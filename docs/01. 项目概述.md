# 项目概述

## 项目定位

SmartFlow 是一款本地优先的个人财务管理应用，围绕复式记账组织交易、账户、分录和统计口径。系统目标是让个人财务数据可追溯、可审计、可扩展，同时保持业务规则和工程边界清晰。

## 核心原则

- **复式记账驱动**：每一笔账务事件都必须通过借贷平衡的分录表达，账务真相以 entries 为准。
- **本地优先**：财务数据默认保存在设备本地，导入、备份、同步和 AI 能力都应以用户主动授权为前提。
- **领域分离**：账务核心、信贷、预算等业务域分开描述；跨域协作通过明确的业务关系和架构决策约束。
- **可追溯变更**：已入账交易不直接覆盖；更正和删除通过冲销与追加记录表达。

## 业务域概览

### 账务核心 ledger

账务核心负责账户、交易、交易分项、复式分录、过账规则、更正、冲销、删除和收支统计口径。普通支出、普通收入、转账、退款、报销、借入、还款、期初余额和余额调整都属于账务核心的账务行为。

### 信贷 credit

信贷域负责分期合同、还款计划、实际还款、提前还本金和提前结清等业务。信贷域通过账务核心完成借入和还款入账，但分期合同自身状态属于 credit。

### 预算 budget

预算域负责按月份和支出分类设置预算目标，并基于账务核心的支出分录计算预算使用情况。预算不改变交易、分录或账户余额。

## 工程概览

- **应用框架**：Flutter
- **Flutter 版本管理**：FVM，版本由仓库根目录 `.fvmrc` 锁定
- **本地数据库**：drift / SQLite
- **状态管理**：Riverpod 3.x + Code Generation
- **路由**：go_router
- **金额**：以最小货币单位整数存储，领域层封装金额语义
- **代码生成**：freezed、json_serializable、drift、riverpod_generator、build_runner
- **图表**：fl_chart
- **UI**：Material 3 + 项目设计系统
- **测试**：flutter_test + mocktail

工程分层与目录组织见《06. 项目结构说明》，视觉规范见《05. 设计系统》。
