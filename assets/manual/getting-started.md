# SmartFlow 的记账方式

SmartFlow 使用复式记账记录财务事实。每笔交易都会同时表达资金或债务的一侧变化，以及收入、支出或另一账户的一侧变化。

## 先理解三个概念

- **账户**：承载余额的对象，例如现金、银行卡、信用卡或贷款。
- **分类**：说明收入或支出的业务用途，例如餐饮、交通或工资。
- **交易**：用户可以识别的一次业务事件，例如买了一顿饭或收到一笔工资。

## 第一次使用

1. 在账户管理中创建常用的资金账户。
2. 根据自己的习惯整理收入和支出分类。
3. 记录一笔真实的支出，检查账户余额是否符合预期。
4. 再记录一笔收入或账户转账，熟悉不同的账务行为。

> 账户决定余额变化，分类决定收支统计。分类不是余额账户，转账也不会被统计为收入或支出。
