# 分期合同与还款计划

分期合同描述一笔负债如何分期偿还，还款计划则把合同拆成按期排列的计划行。

## 两者的区别

| 对象 | 保存内容 |
| --- | --- |
| 合同 | 本金、期数、分期方式、利率和手续费等条款 |
| 还款计划 | 每一期的日期、本金、利息、手续费和状态 |
| 实际还款 | 用户已经完成的核销，并影响计划和合同状态 |

合同参数与计划行是分开的。编辑合同后，只有明确执行重算才会按新参数重建未完成计划；已经完成、部分完成或跳过的计划不会被随意覆盖。

## 分期产品

从“我的 → 分期产品”创建常用贷款产品，配置还款阶段、还款方式、各期间隔、计息方式和固定额算法。产品可编辑、复制和归档；已经用于合同的产品通过归档退出选择列表。

产品不保存本金、期数、实际利率、日期、期末本金、指定固定额和手续费。新建贷款分期时选择产品，再填写本笔贷款的这些信息，可先预览还款计划。

默认沿用产品规则。开启“自定义本笔贷款”后，可以增删、排序阶段和修改计算规则；关闭开关保留本笔修改，只锁定规则编辑。所有修改只影响本笔合同，产品后续修改也不会改变已有贷款。

多阶段合同可以逐阶段编辑。条款保存和计划重算是两个动作；阶段结构或期数发生变化时，需要先点击“按参数重算并预览”再保存。已还、部分已还、跳过及其之前的冻结期次受到保护。

## 多阶段提前还款

在第二阶段中途提前还款时，重算第二阶段的待还尾部及后续完整阶段，前面的冻结期次保持不变。各阶段使用自己的利率和还款规则，后一阶段承接前一阶段重算后的本金。

如果某阶段原定期末本金超过新的期初本金，本次计算把期末本金降至期初本金，该阶段待还部分只计利息和手续费，不再归还本金。原条款保留，撤销提前还款后可以重新计算；最终阶段的气球款仍在末期偿还。

## 常见操作

- 账单分期：把账单消费转换为分期合同。
- 分期还款：针对合同计划完成还款核销。
- 提前还款：提前偿还合同内尚未完成的本金。
- 跳过某期：保留计划时间线，但不把该期当作待还期次。

> 💡 分期还款不一定产生新的账务交易，具体取决于还款形态。合同状态和账户余额分别由信贷域与账务核心负责。
