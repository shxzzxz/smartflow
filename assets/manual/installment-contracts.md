# 分期合同与还款计划

分期合同描述一笔负债如何分期偿还，还款计划则把合同拆成按期排列的计划行。合同名称默认采用借款日期，例如 20261203，可在编辑合同中独立修改。

## 两者的区别

| 对象 | 保存内容 |
| --- | --- |
| 合同 | 本金、期数、分期方式、利率和手续费等条款 |
| 还款计划 | 每一期的日期、本金、利息、手续费和状态 |
| 实际还款 | 用户已经完成的核销，并影响计划和合同状态 |

合同参数与计划行是分开的。编辑合同后，只有明确执行重算才会按新参数重建未完成计划；已经完成、部分完成或跳过的计划不会被随意覆盖。

## 分期产品

从“我的 → 分期产品”创建常用贷款产品，配置还款阶段、还款方式、间隔月数、计息方式和固定额算法。产品可编辑、复制和归档；已经用于合同的产品通过归档退出选择列表。

产品不保存本金、期数、实际利率、日期、期末本金、指定固定额和手续费。新建分期页填写负债账户、本金、借款日期、放款信息和备注；点击“分期配置”进入贷款配置页选择产品、填写本笔条款，确认后返回。入口展示当前分期产品名称，未选择产品时显示“自定义”。

选择“产品模板”后，可直接修改阶段、日期和计算规则；所有修改只影响本笔合同，模板后续修改不会改变已有合同。贷款分期、现金分期和账单分期均通过“分期配置”入口进入同一配置页。

编辑合同页从上到下展示合同汇总、合同配置和还款计划。汇总卡片首行显示合同名称与合同状态。点击合同配置中的“分期配置”进入贷款配置页修改条款，返回不会自动改动计划。还款计划仅允许编辑待还行，其他状态的行置灰。多阶段合同可以逐阶段编辑。条款保存和计划重算是两个动作；阶段结构或期数发生变化时，需要先点击“按配置重算”再保存。已还、部分已还、跳过及其之前的冻结期次受到保护。

## 多阶段提前还款

在第二阶段中途提前还款时，重算第二阶段的待还尾部及后续完整阶段，前面的冻结期次保持不变。各阶段使用自己的利率和还款规则，后一阶段承接前一阶段重算后的本金。

如果某阶段原定期末本金超过新的期初本金，本次计算把期末本金降至期初本金，该阶段待还部分只计利息和手续费，不再归还本金。原条款保留，撤销提前还款后可以重新计算；最终阶段的气球款仍在末期偿还。

## 常见操作

- 账单分期：把账单消费转换为分期合同。
- 分期还款：针对合同计划完成还款核销。
- 提前还款：提前偿还合同内尚未完成的本金。
- 跳过某期：保留计划时间线，但不把该期当作待还期次。

> 💡 分期还款不一定产生新的账务交易，具体取决于还款形态。合同状态和账户余额分别由信贷域与账务核心负责。
