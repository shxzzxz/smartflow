# 账单如何生成

信用账户的账单按账户和出账周期聚合。交易是否进入某张账单，主要取决于它的入账日期，而不是创建日期。

## 账单包含什么

- 账单周期内已经入账的信用账户消费。
- 归属于该账户的分期合同期次。
- 账内交易退款对消费净额的冲减。

账单明细是账务和信贷来源的展示结果。修正交易、期次或入账日期后，账单需要刷新才能反映最新来源。

## 何时生成和刷新

应用运行时每日检查，补齐本期和进行中分期有还款计划的未来账单，并刷新本期与未来。历史缺失账单可从“全部账单 → 创建账单”手动补建；该入口也支持未来账期。

查看账单先展示已有内容，再更新最新来源金额。出账后仍可刷新，修正交易或计划即可更正应还；创建账户、办理分期和调整还款日不立即生成账单。

账户详情展示本期和最近一期未来账单；没有未来账单时只展示本期。其他期次可以进入“全部账单”查看。

修改出账日从下一账期生效，本期窗口保留，未来账单重新生成或调整；手动创建的未来账单同样参与重建。修改某张账单的消费范围只更新该账单，不自动调整相邻账单范围。

## 需要注意的日期

| 日期 | 含义 |
| --- | --- |
| 交易时间 | 实际发生消费或业务事件的时间 |
| 入账时间 | 外部账单或负债结算体系确认的时间 |
| 出账日 | 信用账户划分消费账期的日期 |
| 还款日 | 账单应完成还款的日期 |

> 💡 账单刷新只更新账单展示，不会擅自修改还款计划或合同状态。
