# 如何记录一笔支出

普通支出表示一笔已经发生的消费。它会减少结算账户余额，并进入对应支出分类的统计。

## 操作步骤

- [ ] 在首页打开记账入口。
- [ ] 选择「支出」。
- [ ] 填写金额、交易时间、结算账户和支出分类。
- [ ] 根据需要补充备注或调整入账时间。
- [ ] 保存交易。

## 如何选择账户和分类

- **账户**选择实际支付这笔钱的账户。
- **分类**选择这笔支出的用途，而不是支付方式。
- 如果一次消费包含多个用途，可以使用交易分项拆分金额。

## 从支付截图记账

- [ ] 截取单笔支付或收款结果页、交易详情页，保留实际金额。
- [ ] 在「我的 → 交易 → 截图记账」选择图片，或在系统截图工具、相册中分享单张图片给 SmartFlow。
- [ ] 等待本地识别，核对预填的金额、时间和备注；收支选择实际账户与用途分类，转账选择转出和转入账户。
- [ ] 确认后点击「完成」保存。

图片在设备本地统一解析交易场景与信息，只使用适用来源为“全部来源”的识别规则建议账户和分类。原价和优惠不会代替实际交易金额。账户依次按完整名称、用户规则、常见别名匹配，未匹配时留空；分类未命中时使用同方向“其他”。时间缺失时采用当前时间，账户和分类可以自行补选，普通收支只在疑似重复时显示简短提示。

已确认收款的红包或他人转入识别为收入；零钱通等自有资金转出到银行卡会预填转账金额和可识别的两侧账户，预计到账时间不会作为交易时间。截图未提供来源账户时，转出账户留空。实际金额或普通收支方向不明确时需要手动填写；退款、其余转账和还款会提示对应操作，未成功交易不会预填。

## 配置识别规则

在「我的 → 交易 → 识别规则」分别管理账户规则和分类规则。填写关键词和适用来源，选择应用中的目标账户或分类。例如“6620”对应自己的付款账户，“瑞幸”对应自己的饮料分类。列表第一行显示关键词，第二行显示目标与来源。长按整行拖动排序，或在更多菜单中置顶；按列表从上到下取第一个启用且目标可用的命中结果。

系统提供分类默认规则，账户规则由自己创建。所有规则都可在更多菜单中启用、禁用、编辑和删除。目标被删除或归档时跳过规则，需要重新选择目标；删除内置规则后不会在下次启动时恢复。截图记账只使用全部来源规则；账单导入使用全部来源与对应来源的规则，指定来源的规则仍可配置并用于账单导入。分类主要按商户和商品建议，例如豆浆、油条归早餐，烤鱼、拉面、包子归食品餐饮；理发、美容分别归居家生活下的同名分类。所有建议都需在记账页核对后保存。微信账单导入共享分类规则，账单账户与识别分类都通过来源映射确认。

> ⚠️ 退款、报销和还款不是普通支出。它们有各自的账务表达和后续状态，建议从原交易详情进入对应操作。
