# SmartFlow

SmartFlow 是一款基于复式记账法的个人财务管理 Android 应用。项目采用 Flutter 重写，数据优先存储在本地设备。

## 开发环境

项目使用 FVM 管理 Flutter 版本，版本由仓库根目录 `.fvmrc` 锁定。

常用命令：

```powershell
fvm flutter pub get
fvm flutter analyze
fvm flutter test
```
